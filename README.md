# Hackers-Classification
# Описание
Информативный веб-ресурс с классификацией типов хакеров, их мотивами, примерами и методами. Разрабатывается для студентов-первокурсников по ИБ и начинающих специалистов чтобы понять ландшафт угроз и этические аспекты кибербезопасности.
# Требования
- Минимум 10 страниц контента
- Адаптивный дизайн (мобильный/десктоп)
- Ссылки на достоверные источники
- Четкая структура: типы, мотивы, кейсы
# Ограничения
Запрещены вымышленные сценарии атак, пропаганды. Домен строго образовательный.
